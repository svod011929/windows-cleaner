# 🛡️ Улучшенный Очиститель Windows

Безопасная, оптимизированная утилита очистки системы для Windows 10/11 с комплексными функциями безопасности и системой бэкапов.

## ✨ Возможности

- **🔒 Безопасные операции**: Защита системных файлов и валидация путей
- **📦 Система бэкапов**: Автоматическое резервное копирование перед удалением
- **🛡️ Управление правами**: Умное повышение привилегий
- **📊 Комплексное логирование**: Детальное отслеживание операций
- **⚡ Оптимизированная производительность**: Быстрое сканирование и очистка

## 🚀 Быстрый старт

### Автоматическая установка
1. Скачайте последнюю версию
2. Запустите `install.bat` (Стандартная) или `install.ps1` (Функции администратора)
3. Запустите через `run_cleaner.bat`

### Ручная установка
```bash
git clone https://github.com/yourusername/windows-cleaner.git
cd windows-cleaner
python -m venv cleaner_venv
cleaner_venv\Scripts\activate
pip install -r requirements.txt
python enhanced_cleaner.py
📋 Системные требования
Windows 10/11 (x64)

Python 3.8+

50MB свободного места для бэкапов

🛠️ Функции безопасности
Защита системных путей

Предварительное резервное копирование

Подтверждение пользователя для всех операций

Комплексная обработка ошибок

Логирование операций и возможность отката
